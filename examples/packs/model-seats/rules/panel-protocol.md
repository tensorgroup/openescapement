## Multi-model panel protocol

When convening more than one model on the same target (a diff, a plan, a design
question), follow this protocol:

1. **One shared brief.** Same target, stack context, focus dimensions, and output
   shape (findings with file:line and severity; "no significant findings" is a valid
   answer) for every seat.
2. **Independence first.** Seats produce round-1 output in parallel without seeing
   each other. Agreement between blind reviewers is the panel's strongest signal;
   showing seats each other's output first builds an echo chamber.
3. **Targeted cross-examination.** Relay only the specific disputed claim to the
   other seat's resumed session — never the whole transcript. Apply the substance
   bar and rebuttal caps from the seat policy.
4. **Verification gate.** The moderator verifies every surviving finding against the
   actual code before acting or reporting. Seats advise; evidence decides.
5. **Mandatory outcome logging.** Append a structured record per panel: seats, rounds,
   immediate-agreement flag, and each dispute (one-line summary, challenger, each seat's
   proposal, winner, reason). Record the findings themselves per seat (claim, reference,
   the moderator's confirmed/refuted/partial verdict, evidence checked, action taken),
   grouped across seats, so that a finding only one seat raised is derivable as that
   seat's unique catch rather than a count. An unlogged panel does not count toward any
   seat's record.
