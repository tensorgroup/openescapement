# Gemini 3.7 Flash governance (gemini-3.7-flash)

- `gemini-3.7-flash` is a coding model only where a configuration already pins it; it was superseded by `gemini-3.8-flash` three weeks after release at the same limits and the same price.
- Start new work on `gemini-3.8-flash` instead, and migrate saved configurations when convenient.
- Keep planning and plan-checking on `gemini-3.1-pro-preview`, and run bulk work on `gemini-3.5-flash-lite`.

See the Google model guidance page for sources and full governance notes.
