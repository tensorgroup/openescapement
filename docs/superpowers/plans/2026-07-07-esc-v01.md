# OpenEscapement v0.1 (`esc`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go CLI `esc` that syncs signed, hash-pinned policy packs from git repos into agent instruction files (managed blocks), skills dirs, `.mcp.json`, and GOVERNANCE.md, with drift detection and an opt-in CI gate.

**Architecture:** Stateless verb CLI; all state in `.escapement/config.yaml` + `.escapement/escapement.lock`. Pipeline: fetch (system git) → verify (signatures, hashes) → parse → compose → render → validate constraints → write atomically → lock. `status` runs the pipeline read-only and classifies drift.

**Tech Stack:** Go 1.24, stdlib `flag` subcommands (no CLI framework), `gopkg.in/yaml.v3` (only external dep), system `git` via `os/exec`.

## Global Constraints

- Module path: `github.com/tensorgroup/openescapement`
- Binary: `esc` (`cmd/esc`)
- External deps: `gopkg.in/yaml.v3` ONLY. Everything else stdlib.
- Hashes: SHA-256, rendered as `sha256:<hex>`
- All file writes atomic: temp file in same dir + `os.Rename`
- Bytes outside a managed block are NEVER modified
- Sentinel errors: `ErrSignature`, `ErrLockMismatch`, `ErrConstraint`, `ErrManifest`, `ErrFetch` in `internal/esc/errs.go`
- Exit codes: 0 ok; 1 drift/constraint findings (`status --check`); 2 usage error; 3 integrity/signature failure; 4 other runtime error
- Tests: `go test ./...` green at every commit; integration tests use real temp git repos (no mocks); renderer uses golden files under `internal/render/testdata/`
- TDD per task: failing test → minimal code → pass → commit

Interfaces (produced once, consumed everywhere):

```go
// pack
type Pack struct { Dir string; Manifest Manifest; Fragments []Fragment }
type Manifest struct { Schema int; Name, Version, Description string; Rules []string;
  Skills []string; MCP MCPSpec; Catalog []CatalogEntry; Constraints Constraints }
type CatalogEntry struct { Name, Category, Status, Notes string } // status: preferred|allowed|review-required|banned
type Constraints struct { MaxFileBytes int `yaml:"max_file_bytes"`; ForbiddenPatterns []string `yaml:"forbidden_patterns"` }
type Fragment struct { Path string; Targets []string; Body string }
func Load(dir string) (*Pack, error)
func DirHash(dir string) (string, error)

// config
type PackRef struct { Source, Ref, Trust string }
type Config struct { Schema int; Packs []PackRef; AllowedSignersFile string; Targets []string }
func Load(root string) (*Config, error); func (c *Config) Save(root string) error

// source
type FetchResult struct { Dir, Commit string } // Dir = pack subdir on disk
func Fetch(ctx context.Context, src PackRef, cacheDir string, repoRoot string) (*FetchResult, error)
func VerifyRef(repoDir, ref, allowedSigners string) error

// lockfile
type LockPack struct { Source, Ref, Commit, Hash string }
type LockArtifact struct { Path, Kind, Hash string; Keys []string } // kind: block|file|dir|json-keys
type Lock struct { Schema int; Packs []LockPack; Artifacts []LockArtifact }
func Load(root string) (*Lock, error); func (l *Lock) Save(root string) error

// render
const TargetClaude/TargetAgents/TargetGemini/TargetGovernance/TargetSkills/TargetMCP
func Compose(packs []*pack.Pack, target string) string
func Governance(packs []*pack.Pack) string
func Splice(existing []byte, body string, meta BlockMeta) ([]byte, error)
func Extract(file []byte) (*Block, error) // nil if absent
func BodyHash(body string) string
func Validate(merged []byte, cs []pack.Constraints) []Violation
func MergeMCP(existing []byte, servers map[string]any) ([]byte, []string, error)

// engine
type Artifact struct { Path, Kind, Hash string; Keys []string; Content []byte } // desired state
type PlanResult struct { Packs []lockfile.LockPack; Artifacts []Artifact; PackObjs []*pack.Pack; Violations []render.Violation }
func Plan(ctx, root string, opts PlanOpts) (*PlanResult, error) // opts: SkipVerify for status of already-locked? no — always verify
func Apply(root string, p *PlanResult) error
func Status(ctx, root string) (*StatusResult, error)
```
