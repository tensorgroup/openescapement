Your AI rules, in every repo, checked in CI.

esc writes your organization's rules into the files that coding agents read every session. It writes them from one signed rule pack. A CI check fails when a repo drifts from the pack.

Pack: your org writes the rules once. Sync: esc writes them into each repo. Check: CI fails when the repo drifts.
